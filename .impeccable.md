# MyCut Design Context

## Users

MyCut serves content creators and video editors who turn trends, outlines, scripts, and source footage into publishable short-form video. The primary environment is a desktop web workspace. Users value clear status, predictable workflows, and fast access to the next meaningful action.

## Brand

MyCut should feel calm, precise, professional, and quietly confident. The interface should help users focus on the work instead of calling attention to itself.

## Aesthetic Direction

- Use a pure white light-theme workspace with restrained neutral support surfaces and a peach-to-pink brand gradient. Treat the gradient as an accent, not as a page background.
- Preserve first-class Light and Dark themes; dark surfaces are deliberately rebalanced rather than inverted.
- Use MiSans for every textual role, including the wordmark, UI copy, data, and timecodes.
- Use Solar icons throughout the product: Linear by default; use the corresponding Bold icon with an actual peach-to-pink gradient fill for selected navigation. Bold or Bold Duotone icons on filled buttons and brand surfaces are white.
- Prefer generous whitespace, clear hierarchy, borderless large surfaces, and restrained soft elevation.
- Follow a shared iOS-like radius scale: 12px controls, 16px media, 20px cards, and 24px panels or dialogs. Reserve fully rounded shapes for badges, avatars, and status dots.
- Present clips and other media as professional editing-tool cards with a 16:9 preview, compact overlays, metadata, timecodes, and direct actions.
- Reserve the brand gradient for the main heading, primary action, active progress, and sparse ambient glow. Avoid toy-like color, neon effects, excessive glassmorphism, and generic AI card grids.

## Design Principles

1. Give each view one obvious primary action.
2. Reveal advanced choices progressively without changing the existing product workflow.
3. Drive all components from shared semantic tokens so Ant Design and shadcn can coexist during migration.
4. Keep text contrast, keyboard focus, touch targets, and reduced-motion behavior accessible.
5. Own shadcn component source locally and migrate surfaces incrementally without changing routes, state, APIs, or business logic.
